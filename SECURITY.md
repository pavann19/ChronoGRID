# Security policy

This repository is a local research demonstration without a support or response-time agreement. Report vulnerabilities using GitHub private vulnerability reporting when available. Include reproduction steps and keep credentials out of public issues.

Diagnostics and forecast replay require bearer tokens; health probes remain open. Registry checks bind local model and metadata bytes before loading. Pickled research models are trusted fixtures and must never come from untrusted uploads. Dependency audit results apply to the exact dependency set checked.

See [evaluation](docs/evaluation.md) and [the runbook](docs/runbook.md) for scope and operational limits. Local checks do not establish security in an operated service or independent evidence custody.
